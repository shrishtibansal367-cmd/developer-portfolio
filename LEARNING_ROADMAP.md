## 3. Six-Semester Roadmap

### Semester 1 (Current) — Foundations
* **University Subjects:** CSE103 (Programming for Problem Solving / Python), Engineering Mathematics-I, Basic Electrical/Electronics, Physics
* **Core Skills:** Python basics, Linux terminal, Git/GitHub, binary number systems
* **Projects:** CSE103 Lab Portfolio, GitHub profile README
* **Personal Passion Project Idea:** [e.g., A terminal-based KRMU GPA & Attendance Tracker built in Python]
* **Certifications:** HackerRank Python (Basic) — attempt before Semester 2 begins
* **Platforms:** HackerRank (30+ problems), freeCodeCamp intro labs
* **Weekly Habit:** 2–3 hours of self-study beyond scheduled lab hours

### Semester 2 — Core Computer Science
* **University Subjects:** Data Structures, Object-Oriented Programming (C++/Python), Digital Logic Design, Discrete Mathematics
* **Core Skills:** Arrays, linked lists, stacks, queues, trees; Python OOP (classes, inheritance, file I/O), C++ basics
* **Projects:** DSA Implementation Repository — code at least 5 data structures from scratch with a detailed README
* **Certifications:** NPTEL *Introduction to Programming in Python*
* **Platforms:** LeetCode Easy (50 problems target), GeeksforGeeks DSA track

### Semester 3 — Intermediate
* **University Subjects:** Database Management Systems (DBMS), Operating Systems, Computer Organization & Architecture
* **Core Skills:** MySQL, SQL joins, indexes, HTML + CSS + JavaScript
* **Projects:** Student Record Management System (Python + MySQL)
* **Certifications:** Google IT Support Certificate (Coursera — free to audit)
* **Platforms:** HackerRank SQL track, freeCodeCamp Responsive Web Design cert

### Semester 4 — Intermediate-Advanced
* **University Subjects:** Design & Analysis of Algorithms (DAA), Computer Networks, Software Engineering
* **Core Skills:** Web framework (Flask or Django), REST API development
* **Projects:** Full-stack mini-project (e.g., Task Manager App using Flask + SQLite + HTML/CSS)
* **Certifications:** AWS Cloud Practitioner Essentials (free on AWS Skill Builder)
* **Platforms:** LeetCode Medium (30 problems target), HackerRank Problem Solving

### Semester 5 — Specialisation (Track A: Full-Stack Development)
*(Note: Replace this section if you chose Track B, C, or D in Step 1)*
* **University Subjects:** Web Technologies, Artificial Intelligence / Machine Learning basics, Department Electives
* **Core Skills:** React.js, Node.js, MongoDB, Docker basics, REST + GraphQL APIs
* **Projects:** 2 Full-Stack specialisation projects with live deployment and full documentation
* **Internship:** Target a 2-month summer internship (start applying in Semester 4)
